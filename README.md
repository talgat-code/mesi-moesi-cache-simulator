# mesi-moesi-cache-simulator

Starter project on React + Vite + TypeScript for a cache coherence simulator.

## Stack

- React 19
- Vite 8
- TypeScript 6
- ESLint

## Project structure

```text
src/
  app/          # root app layer
  components/   # reusable UI blocks
  pages/        # page-level components
  shared/       # config, types, shared UI
  styles/       # global styles
```

## Run locally

```bash
npm install
npm run dev
```

After launch Vite will show the local address in the terminal, usually `http://localhost:5173`.

## Available scripts

- `npm run dev` - start dev server
- `npm run build` - build production bundle
- `npm run preview` - preview build locally
- `npm run lint` - run ESLint
